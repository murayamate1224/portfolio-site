# Next.js Portfolio

A modern, responsive portfolio site for a full-stack developer and designer, built with Next.js, React, TypeScript, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `app/page.tsx` to update the portfolio content, projects, skills, social links, and contact email. Edit `app/globals.css` to change the visual style and color palette.
